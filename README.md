🦠 Re-Poopulate

Guided help to rebuild your gut biome.

The practical guide on what to eat after a colonoscopy, antibiotics, or food poisoning.

Live Web App: getrepoopulate.com

🌟 Overview

Re-Poopulate is a mobile-first Progressive Web App (PWA) designed to give clear, food-first guidance for restoring gut health following major digestive disruptions. Rather than relying on overwhelming medical jargon, Re-Poopulate provides actionable phase-by-phase food recommendations tailored to specific recovery tracks.

🎯 Key Features

3 Tailored Recovery Tracks:

🏥 Post-Colonoscopy: 3-Day Mucosal & Flora Reset

💊 Post-Antibiotics: 14-Day Microbe Recovery Protocol

🤢 Post-Food Bug: 7-Day Gastro Re-Entry Protocol

Progressive Disclosure Science ("Geek Out 🧪"): Clickable expansion panels on food cards detailing the exact enzymatic, biological, and microbial mechanics behind each recommendation.

Dietary Filtering: Seamless toggles for Vegetarian, Vegan, and Gluten-Free (GF) preferences.

Full Progressive Web App (PWA): Mobile home-screen installation support with offline caching capability.

🛠️ Tech Stack

Frontend: Single-file HTML5, Tailwind CSS (CDN), Vanilla JavaScript

PWA Integration: Web App Manifest + Service Worker

Deployment & Hosting: Vercel (Auto-deployed via GitHub push)

Domain Management: Porkbun DNS

📄 Discharge Disclaimer

Re-Poopulate provides practical food suggestions for gentle digestion and microbiome support. Always follow your physician or gastroenterologist's specific discharge instructions.
